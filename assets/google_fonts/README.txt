Thu muc nay de bundle font "Be Vietnam Pro" cho app chay OFFLINE (khi demo khong co mang).

Cach lam:
1. Tai font tai https://fonts.google.com/specimen/Be+Vietnam+Pro
2. Copy cac file .ttf vao thu muc nay, giu NGUYEN ten file, vi du:
   BeVietnamPro-Regular.ttf
   BeVietnamPro-Medium.ttf
   BeVietnamPro-SemiBold.ttf
   BeVietnamPro-Bold.ttf
   BeVietnamPro-ExtraBold.ttf
3. Chay lai: flutter pub get && flutter run
   (goi google_fonts se tu dong dung file trong assets truoc, khong can tai tu mang)

Neu khong bundle font: app van chay binh thuong khi co mang (font duoc tai lan dau),
con khi khong co mang se tam dung font mac dinh cua he thong.
