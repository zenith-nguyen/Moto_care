# Coding-agent entry point

Read [`docs/PROJECT_CONTEXT.md`](docs/PROJECT_CONTEXT.md) before working.

Always read [`docs/PROGRESS.md`](docs/PROGRESS.md) first to understand the current state — do not ask again about decisions already recorded there. After completing any task (even a small one), UPDATE `docs/PROGRESS.md` with completed work, next steps, and any new decisions.

Keep changes scoped, do not commit secrets, use Conventional Commits, and run relevant lint and tests before handoff.
